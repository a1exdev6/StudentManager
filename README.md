# StudentManager
一、项目介绍

1.项目名称：学生成绩管理系统

2.项目背景：在校园教学管理中，学生成绩管理是基础且核心的工作。传统人工管理模式存在效率低下、易出现数据错误，且成绩查询、统计、排名等操作繁琐的问题，难以满足日常教学的高效管理需求。该系统可实现成绩录入、修改、查询、统计等功能的自动化，规范数据存储，提升成绩管理的效率与准确性，同时也是提升我的实践编程能力、掌握语言综合应用的优质项目。

3.项目简介：本项目是基于C语言与EasyX图形库开发的学生成绩管理系统，实现了学生成绩的可视化管理。系统提供了友好的图形交互界面，支持学生信息的增加、删除、修改、查询及输出等核心功能，适用于小型教学或班级管理场景。


本项目分为俩个版本，满足不同使用场景：

     控制台版：命令行交互

     EasyX图形版：基于EasyX图形开发，可视化界面操作更直观

二、环境配置

 1.操作系统：Windows
 2.开发工具：Visual Studio 2022
 3.编程语言：C语言
 4.图形库：EasyX

 三、运行步骤

 1.配置VS22022+EasyX图形库
 2.克隆仓库到本地，用VS打开项目
 3.生成解决方案，直接运行程序
 4.按图形界面操作即可

 四、功能说明

(1)录入学生信息（2）增加学生信息（3）删除学生信息（4）修改学生信息（5）查询学生信息

五、项目结构

1.头文件：StudentManager.h 宏定义、结构体声明、函数声明
2.源文件：main.c 程序入口、菜单交互逻辑；main.cpp 程序入口、EasyX图形界面初始化与菜单交互逻辑
StudentManager.c 核心业务实现逻辑（录入、查询、修改、删除、统计、文件读写）
